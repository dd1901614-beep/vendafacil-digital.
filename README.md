# VendaFácil Digital

Site de criação de artes digitais e materiais promocionais.

## Status

Projeto em desenvolvimento. A versão local foi testada em navegador móvel simulado: 15/15 imagens carregaram, prévia gerada, botão de download habilitado, sem erros JavaScript observados nesse teste.

**Não está liberado para receber pedidos ou pagamentos.** Geração de imagens por IA, pagamento Pix/cartão, entrega após pagamento e publicação pública do site ainda dependem de implementação, configuração e testes.

## Privacidade

Não adicionar senhas, tokens de API, chaves Pix privadas ou dados pessoais a este repositório público.
